# Automatic File Organizer

## About the Project
This Python project automatically organizes files into folders based on their file extensions.

## Features
- Organizes PDF and document files.
- Separates images, videos, archives, and code files.
- Shows a preview before moving files.
- Handles duplicate filenames.
- Handles permission errors.
- Displays a summary after organizing files.

## Technologies Used
- Python
- os
- shutil

## How to Run
1. Install Python.
2. Download `file_organizer.py`.
3. Open the terminal in the project folder.
4. Run:

```bash
python file_organizer.py
```

5. Enter the folder path you want to organize.
6. Type `YES` to confirm moving the files.
